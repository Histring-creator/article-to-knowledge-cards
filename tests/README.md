# 本地行为试跑

以下均为本项目自写测试材料，不使用第三方文章。由当前 Codex 按 SKILL.md 执行并人工检查；不是独立模型评测，也不是自动化语义测试。每例保留完整输入与实际输出，便于重跑。

## 1. 方法教程（模拟粘贴文章）

输入：

> 本文介绍读书笔记的五个动作。先写阅读问题，用问题明确这次阅读要寻找什么。然后用自己的话概括主张，检查自己是否理解作者。例如，把一段长论述压缩为一句话。记录引文时同时记下页码，以便回到原处核对。把自己的推测与作者的说法分开标记，避免混淆。最后列出尚未解决的问题，留待后续阅读。笔记版面可以整洁，也可以随意，本文不讨论排版。

输出：

### 卡片 1：用问题明确阅读目标
- **核心知识**：阅读前写下本次要寻找答案的问题。
- **简明解释**：用阅读问题明确这次阅读的目标。
- **自测问题**：阅读问题要帮助明确什么？

### 卡片 2：用自己的话概括主张
- **核心知识**：用自己的话概括作者的主张，以检查理解。
- **简明解释**：将作者的论述改用自己的语言表达。
- **例子**：把一段长论述压缩为一句话。

### 卡片 3：引文同时记录页码
- **核心知识**：记录引文时同时记录页码。
- **简明解释**：页码方便回到原处核对引文。
- **自测问题**：为什么记录引文时要记页码？

### 卡片 4：区分推测与作者说法
- **核心知识**：将自己的推测和作者的说法分开标记。
- **简明解释**：分开标记可以避免混淆两者。
- **自测问题**：笔记中哪两类内容应分开标记？

### 卡片 5：保留未解决的问题
- **核心知识**：列出尚未解决的问题，留待后续阅读。
- **简明解释**：用问题清单记录本次阅读仍未解决的内容。
- **自测问题**：阅读后尚未解决的问题应如何处理？

检查：5 张；各有单一重点；未将无关排版内容制卡；仅第 2 张使用原文例子，其余使用可回答的自测问题。通过。

## 2. 研究摘要（本地 Markdown 输入）

输入文件：[research.md](research.md)。执行时完整读取该文件。

输出：

原文支持 3 个独立知识点，因此生成 3 张卡片。

### 卡片 1：本次观察中的关联
- **核心知识**：这次观察中，每周到馆至少两次的学生，其阅读自评更高。
- **简明解释**：这是对某校 30 名自愿参加者为期一周的观察结果，衡量的是阅读自评。
- **自测问题**：这次观察比较的是哪项自评？

### 卡片 2：关联不能确定因果
- **核心知识**：该观察不能确定到馆使阅读能力提高。
- **简明解释**：研究者没有随机分组，原文只报告关联。
- **自测问题**：能否据此断定到馆提高阅读能力？

### 卡片 3：样本限制推广范围
- **核心知识**：作者提醒，样本来自一所学校，不能据此推广到所有学生。
- **简明解释**：结论的适用范围受这次样本来源限制。
- **自测问题**：作者指出了哪项样本来源限制？

检查：3 张；样本量和观察期留在结论的解释中，没有拆成凑数卡片；保留“自评”“观察”和归属；没有补充提高阅读能力的建议。通过。
